## 1 Purpose

Assemble the daemon into a supervised pipeline so Sentinel works end-to-end:
`Feed (WS/REST or MockPerpl) → LiveState → reflex::decide → Policy → Executor
→ alerts + events`, with deterministic fixture replay, a health surface, and
graceful shutdown. After P06, `scripts/crash-demo.sh` replays a real crash
path and shows the full save sequence with zero manual steps.

Dependencies already on disk and verified: `crates/sentinel/src/{args.rs,
reflex.rs, pipeline.rs, notify.rs, health.rs, main.rs}` (stubs = contract),
`perpl/{mod,ws}.rs` (feed), `execution/*` (P05), `sentinel-core` (P04/P05).

## 2 Scope / non-goals

**In scope:** `pipeline.rs`, `notify.rs`, `health.rs` implementations, their
in-module tests, the verifier's corpus.

**Non-goals:** strategy brain (P07), Nansen (P09), audit journal/anchor (P10),
telegram commands/approvals (P11), dashboard (P15), task-panic supervision
and retry storms (P16). Alert text is plain (MarkdownV2 is P11). `mainnet`
mode is refused by the daemon (P16 deploys testnet).

## 3 Frozen surfaces

- `args.rs` (parent, done): `Cli { mode: Option<ExecutionMode>, replay:
  Option<PathBuf> }`, strict `--mode dry-run|testnet|mainnet` / `--replay`.
- `health.rs`: `HealthState{started, last_feed_ms, mode, version}`,
  `render(now_ms) -> Value` = `{"uptime_s": u64, "feed_age_s": u64|null,
  "mode": "DRY_RUN|TESTNET|MAINNET", "version": "..."}` (feed_age = now_ms −
  last_feed_ms when set, null when never), `router()`, `serve(state, port,
  shutdown)` (axum; bind `0.0.0.0:port`; graceful on shutdown watch).
- `notify.rs`: `Alert{kind, market_id, text, at_ms}`, `AlertKind`
  (`TierChange{from,to,distance_pct}`, `ReflexAction{decision_id,status,size,
  client_order_id}`, `ConsultScheduled{tier}`, `FeedStale{secs}`),
  `AlertSink`, `TracingSink` (target `sentinel::alert`), `RecordingSink`
  (shared `Arc<Mutex<Vec<Alert>>>`), `TelegramSink` (teloxide
  `Bot::new`+`send_message`, plain text), `DedupeSink` (**clock = `at_ms`**):
  suppress a `TierChange` whose `(market_id, to)` equals the stored
  `(market_id, tier)` unless `now − stored_ms >= RED_REALERT_MS` and the tier
  is `Red`; update the stored timestamp whenever an alert passes; non-
  `TierChange` alerts always pass. Tier-change text v1 must contain symbol,
  market id, from→to and rendered distance (e.g. `"🟡 ETH#32 GREEN→YELLOW ·
  distance 24.31% · consult scheduled"`); reflex text must contain action,
  size, client order id and status.

## 4 Pipeline semantics (normative)

`Pipeline::run(shutdown)`:

1. Startup: `feed.context()` → `LiveState.set_markets`; `feed.snapshot()` →
   initial account; emit `Started{mode, replay, markets, positions, at_ms}`.
   In `RunMode::Replay`, `at_ms` = initial `snapshot_ts` ms; else wall ms.
2. Event loop: `feed.stream()` receiver; `select!` against `shutdown.changed()`.
   On each event: `LiveState::apply(event)` **then** evaluate.
3. `LiveState::apply` rules:
   - `MarkPrice{m,p}`: `marks[m]=p`; for every position of `m`:
     `mark_price=Some(p)`, `unrealized_pnl=(p−entry)×size`;
     `equity = base_balance + Σ uPnL`. Time: mark ts. → `StateDelta::Risk`.
   - `Snapshot{state}`: replace account; merge snapshot position marks into
     `marks`; `base_balance = equity − Σ uPnL`. Time: `snapshot_ts`. → `Risk`.
   - `Update{u}`: `free_balance=u.free_balance`, `fee_tier`; keep marks;
     `equity = base_balance + Σ uPnL`. Time unchanged. → `Risk`.
   - `FeedStale{secs}`: `stale_secs=Some(secs)`. → `Stale`.
   - `Reconnected{attempt}`. → `Reconnected`.
   - Any event clears `stale_secs` and stores its timestamp as `now_ms`
     (wall in live, event ts in replay).
4. Evaluation trigger: `Risk` deltas always evaluate in replay; in live mode
   at most once per `LIVE_EVAL_INTERVAL` (wall). `Stale`/`Reconnected` never
   evaluate (they only update state and emit events/alerts).
5. Evaluation: `reflex::decide(account, markets, cfg, reflex_state, day,
   &mut seq, now_ms, quality)` — `quality = Stale{secs} | Fresh`. For every
   `PlannedAction`: emit `Decision` (rendered verdict/action); track tier
   transitions per market → on change emit `TierChanged` + sink alert; on
   entering `Yellow` emit `ConsultScheduled` + sink alert (`Orange`/`Red`
   entries: tier alert only — consult hooks arrive in P07).
6. Execution: for a planned `order` with `verdict == Allow`: submit via the
   executor; `Ok(report)` → emit `Executed` (status/size/avg) + sink
   `ReflexAction` alert + `day.actions_today += 1`; `Err(DuplicateOrder)` →
   `DuplicateSuppressed`; other `Err` → `SubmitFailed`. Denied/approval/none
   → `Decision` only. Sink errors are `warn!`-logged, never fatal.
7. Shutdown: flip → stop consuming, emit `Shutdown{at_ms}`, return the full
   `PipelineOutcome`. No panics; all producers stop when the receiver drops.

## 5 Mode/executor matrix (parent-wired in `main.rs`)

| Invocation | Feed | Executor |
|---|---|---|
| `--replay <f>` (any mode) | `MockPerpl` | `DryRunExecutor` **unguarded**, no health server |
| `--mode dry-run` | `LivePerpl` | `GuardedExecutor<DryRunExecutor>` + health |
| `--mode testnet` | `LivePerpl` | `GuardedExecutor<PerplExecutor>` + health |
| `--mode mainnet` | refused (`bail!`) | — |

Executors read positions through `pipeline::StateProbe` over the shared
`LiveState` (current marks), not through the feed.

## 6 Determinism contract (§7)

Same fixture + same config ⇒ **identical `PipelineOutcome::to_jsonl()`**,
including alert texts and ordering. Replay clock: latest applied event
timestamp (no `SystemTime` anywhere in replay decisions). Pacing:
`SENTINEL_MOCK_PACE` (divisor, default 50) and `SENTINEL_MOCK_CAP_MS` (cap,
default 100; used by the crash demo to slow down and by tests to skip
sleeps: divisor ≥ fixture span/1e3 ⇒ no sleeps). All wall-clock readings in
replay are limited to `tracing` timestamps (not compared).

## 7 Crash fixture (parent-owned, `tests/fixtures/perpl/crash-scenario.jsonl`)

ETH (testnet id 32) long: entry `2700.00`, size `+10.000`, collateral
`13560` AUSD, `lv=200` → derived liq `= 2700×1.05 − 1356 = 1479.00`
(`risk.rs` formula; mmr `0.05`). Marks linear `2112.86 → 1573.40` in 24 WS
steps (25 s logical each, 600 s span) ⇒ distance `30.0% → 6.0%`, crossing
soft 25 % (→Yellow), warn 15 % (→Orange), hard 8 % (→Red). BTC (id 16)
position stays Green as the contrast. REST lines: context (ETH+BTC), ticker,
wallet, positions. WS: initial `mt:19`+`mt:26`, then `mt:9` steps with a
`mt:26` re-send every 6th step (MockPerpl re-composes snapshots with current
marks). Replay does not apply fills to state (documented; P13 models
savings). Demo env in `scripts/crash-demo.sh`: `MARKET_ALLOWLIST=32,16`,
`MAX_ORDER_SIZE_USD=100000`, `REQUIRE_APPROVAL_ABOVE_USD=100000`,
`REFLEX_COOLDOWN_SECS=60`, `SENTINEL_MOCK_PACE=1`, `SENTINEL_MOCK_CAP_MS≈3200`
(≈80 s wall). Expected sequence: Yellow consult-scheduled → Orange reduce
2.500 → Red reduce 5.000, alerts each step.

## 9 Required tests

- `pipeline` (in-module + `tests/pipeline_determinism.rs` is parent's):
  `LiveState::apply` rules table (marks revaluation, snapshot base_balance,
  update patch, stale set/clear), `StateProbe` reads, event ordering on a
  small inline fixture (in-module, tiny WS set), shutdown mid-stream returns
  `Ok` with `Shutdown` once.
- `notify` (in-module): dedupe matrix — first alert passes; same
  `(market,tier)` suppressed; tier **change** passes; persistent Red re-alert
  at exactly `>= 15 min` and not before; non-Red never re-alerts; non-
  tier-change alerts always pass; `RecordingSink` captures; text contains
  required fields.
- `health` (in-module): `render` math (never/5 s ago), JSON shape; `serve`
  on an ephemeral port answers `GET /healthz` 200 + shape (reqwest), stops
  on shutdown watch.
- Verifier (`p06_adversarial.rs`, own fixture): two-run determinism on its
  own scenario (JSONL equality), expected event sequence (Started → … →
  TierChanged transitions → ConsultScheduled on Yellow → Executed → Shutdown),
  notify boundary matrix black-box, health shape via spawned server,
  shutdown drain within a bounded timeout.
