## 1 Purpose

Deliver `crates/sentinel/src/perpl/` — the sensory system of Sentinel: Ed25519
request signing, a typed REST client for Perpl gateway snapshots and history,
and the two WebSocket feeds (market-data + trading) that emit domain events on
an mpsc bus with staleness detection and auto-reconnect. When this lands,
`read-positions` can print a real account snapshot and later prompts build the
reflex engine and executor on top of the frozen `PerplFeed` trait.

Ground truth: `docs/FACTS.md` §1 (verified constants, scales, endpoints) and
`vendor/api-docs/*.md` (pinned official docs). Where this spec and a raw
payload disagree, the spec wins for field *shapes*; report the disagreement.

## 3 Data formats (normative)

### 3.1 REST canonical string

Six fields joined by `\n`:
`chain_id`, `METHOD`, `request-target (path+query exactly as sent)`,
`timestamp_ms (decimal string)`, `nonce (16 random bytes, base64url no pad)`,
`sha256(body) lowercase hex` (`""` body → sha256 of empty).

**Vector REST-1** (chain 143, GET, no body):
```
canonical = "143\nGET\n/v1/trading/fills?count=100\n1728000000000\nAAAAAAAAAAAAAAAAAAAAAA\ne3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
```
(`sha256("")` verified: `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`.)

**Vector REST-2** (chain 10143, POST, body `{"d":[]}` literal 7 bytes):
```
canonical = "10143\nPOST\n/v1/trading/orders\n1728000001000\nAAAAAAAAAAAAAAAAAAAAAA\n088214f816e99a2f4aedb5323c1c2eaf8b8143df9424ec46759966ddd9b72dd3"
```
(`sha256('{"d":[]}')` verified: `088214f816e99a2f4aedb5323c1c2eaf8b8143df9424ec46759966ddd9b72dd3`.)

Signature = `base64url(ed25519_sign(seed, canonical))`, **no padding**.
Headers, in this order: `X-API-Key`, `X-API-Timestamp`, `X-API-Nonce`,
`X-API-Signature`.

### 3.2 WS canonical string

Four fields joined by `\n`: `chain_id`, literal `trading-ws-signin`,
`timestamp_ms`, `nonce`. **Vector WS-1**:
```
canonical = "10143\ntrading-ws-signin\n1728000000000\nAAAAAAAAAAAAAAAAAAAAAA"
```
Frame (first message on `/ws/v1/trading`):
`{"mt":29,"chain_id":10143,"api_key":"...","timestamp":"1728000000000","nonce":"...","signature":"..."}`
(`api_key` is the opaque token; fresh timestamp+nonce per call.)

### 3.3 Raw payload mapping (the rules; apply exactly)

| Raw (venue JSON) | Domain | Rule |
|---|---|---|
| `config.price_decimals`, `config.size_decimals` | `Market` | direct |
| price fields (`ep`, `xp`, `mrk`, fill `p`) | `Decimal` | `raw / 10^price_decimals` |
| size fields (`s`) | `Decimal` | `raw / 10^size_decimals`; positions: `sd==2` (Short) ⇒ negative |
| amounts (`c`, `fee`, `cfee`, `f`, `a`, `b`, `lb`, `dpnl`, `fnd`) | `Decimal` | `raw / 10^6` (collateral decimals = 6, both networks) |
| `lv` | leverage | `raw / 100` (e.g. 500 ⇒ 5x) |
| `config.initial_margin` | fraction | `100 / raw` (1200 ⇒ 1/12; `max_leverage` = `raw/100` = 12) |
| `config.maintenance_margin` | fraction | `100 / raw` (2000 ⇒ 0.05) |
| `config.maker_fee` / `taker_fee` | micros | direct u64 |
| `min_size` | | always `Decimal::ZERO` — venue minimum is not exposed in context (`min_posting_amount` is collateral-denominated and currently `0`); comment as such |
| `tick_size` | | `Decimal::new(1, price_decimals)` |
| timestamps `{"b":..,"t":ms}` / number / digit-string | `DateTime<Utc>` | take `t`-like ms; `DateTime::from_timestamp_millis`; unparseable ⇒ `None` |
| market lookup | | by `mkt`/`id` in the provided `markets` slice; **unknown id ⇒ `Err(PerplError::Rest("unknown market id <id>"))`** |
| `symbol` empty (BTC/MON mainnet quirk) | | fall back to `name`; `base` = raw `name` |
| position `st` | | keep only `st == 1` (Open); others are ignored |
| positions `mark_price` | | from the `marks` map; without it `None` and `unrealized_pnl = 0` |
| positions `unrealized_pnl` | | `(mark − entry) * signed_size` when mark known, else `Decimal::ZERO` |
| positions `liq_price`, `margin_ratio` | | `None` — gateway does not expose them (P04 derives) |
| `ots` | `opened_at` | via timestamp rule |

## 4 API surface (exact)

The stubs now committed in `crates/sentinel/src/perpl/{auth,types,rest,ws}.rs`
**are the contract**: keep every public signature, type name and doc promise
verbatim, including:

- `auth`: `ApiKeySigner::{from_parts, from_config, chain_id,
  signed_request_headers, ws_signin_frame}` + free fns `canonical_rest`,
  `canonical_ws`, `sign_canonical`, `b64url`, `random_nonce_16`.
  `b64url` uses `base64::engine::general_purpose::URL_SAFE_NO_PAD`.
  `random_nonce_16` uses `getrandom::fill` (NOT rand_core — 0.10 has no OsRng).
  ed25519-dalek v3: `SecretKey = [u8;32]`, `SigningKey::from_bytes(&seed)`,
  `Signer` trait; verify API in registry source
  `~/.cargo/registry/src/*/ed25519-dalek-3.0.0/`.
  `ApiKeySigner` must implement `Debug` **by hand** (redacted).
- `types`: `FillRecord`, `AccountEventRecord`, `AccountUpdate` structs +
  `parse_context`, `parse_positions`, `marks_from_ticker`, `parse_wallet`,
  `account_state`, `parse_account_update`, `parse_fills`,
  `parse_account_history`. `parse_wallet` returns
  `(account_id, free_balance, balance, fee_tier, forward_enabled, lfr)`;
  missing `as[]`/empty ⇒ `Err(PerplError::Rest(...))` (documented as the
  "wallet holds no exchange account" case). `account_state` builds
  `AccountState` with `equity = balance + Σ unrealized_pnl`.
- `rest`: `PerplRest::{new, get_context, get_ticker, get_wallet, get_positions,
  get_orders, get_fills, get_account_history}` returning raw `serde_json::Value`
  (mapping happens in `types`). Retry contract: 3 attempts total, backoff
  250 ms then 1 s, only on 5xx/timeout/connect; never on 4xx; structured
  tracing logs (`method`, `target`, `status`, `latency_ms`) — **never header
  values or bodies beyond a 200-char truncated error excerpt**.
- `ws`: `MarketEvent`, `AccountEvent`, `FeedEvent`, `WsConfig`, `MarketRef`,
  `StaleDetector`, `backoff_base`, `run`. `backoff_base(attempt) =
  min(500 ms · 2^attempt, 30 s)` (exact: 500ms,1s,2s,4s,8s,16s,30s,30s,…).
  `StaleDetector` is edge-triggered: `touch(now_ms)` resets, `observe(now_ms)`
  returns `Some(secs)` exactly once per stale episode (`secs` = whole seconds
  since last touch), `None` otherwise; no touch ever ⇒ `None`.
  `run()` spawns market-data + trading loops sharing the `tx` bus and a
  watch-based shutdown; reconnects forever with `backoff_base`+jitter
  (≤25%) until shutdown flips; emits `FeedEvent::Reconnected{attempt}` after a
  successful reconnect; trading loop sends `mt:29` as first frame, tracks
  heartbeat `sn` from the wallet snapshot and reconnects on gaps, sends a
  `{"mt":1,"t":<ms>}` ping every 30 s; market-data loop subscribes `mt:5`
  `[market-state@<chain_id>, heartbeat@<chain_id>, order-book@<id> …]`;
  incomings touch the shared `StaleDetector`; a 1 s checker emits
  `FeedEvent::FeedStale{secs}` once per episode. Unrecoverable `Err` only for
  startup-level failures (e.g. unparseable URL).
  tokio-tungstenite 0.30: text frames via `Message::text(...)`; check exact
  APIs in `~/.cargo/registry/src/*/tokio-tungstenite-0.30.0/` and
  `tungstenite-0.30.0/`.

## 8 Verification semantics

- `PerplError::Auth` — signing/key problems (auth.rs).
- `PerplError::Rest` — HTTP/parsing problems (rest.rs, types.rs REST paths).
- `PerplError::Ws` — socket/parsing problems (ws.rs paths).
- "Verified" = your cited commands were run by you in this repo, exit code 0,
  with observed output included in your report. The **verifier agent**
  re-derives canonical strings from §3, computes the expected REST-1/REST-2/WS-1
  signatures independently with **Node's `crypto`** (PKCS#8 DER =
  `302e020100300506032b657004220420` ‖ 32-byte seed;
  `crypto.sign(null, Buffer.from(canonical), key)` ⇒ base64url), and runs its
  own adversarial corpus. Writers must not hardcode un-oracled signature bytes.

  `X-API-Key`; 3 attempts on persistent 500 (then `Err`); 1 attempt on 401;
  success path returns parsed JSON.
