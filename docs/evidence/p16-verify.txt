   stringify!(SendMessage)`), so those wiremock mocks never match — the

   its 200. M's suite covers the real success path (case-insensitive
   match, valid `{"ok":true,"result":...}` body: delivered=32) and
   reproduces the observed request path `POST /bot<token>/SendMessage`.
