## 0. Environment prep notes (what the stock flow needed on this machine)
================================================================================

(a) Docker socket: the session user was not in the docker group and
    `docker ps` → "permission denied ... /var/run/docker.sock". Worked around
    with a scoped relay (cleaned up at the end):

      sudo socat UNIX-LISTEN:/home/luna/.hermes/cache/scratch/docker-p12.sock,mode=666,fork,reuseaddr UNIX-CONNECT:/var/run/docker.sock
      export DOCKER_HOST=unix:///home/luna/.hermes/cache/scratch/docker-p12.sock
      # → envio dev log: "Connected to Docker via DOCKER_HOST (unix:///home/luna/.hermes/cache/scratch/docker-p12.sock)"

(b) Host firewall vs docker bridges: a system nftables table dropped ALL
    container↔container traffic (both directions confirmed with file-backed
    `nc` probes: rc=143/SIGTERM from `timeout`, no RST; DNS resolved fine):

      table inet filter {
        chain forward { type filter hook forward priority filter; policy drop; ... }
        chain input   { type filter hook input;   policy drop; ... } }
      # hasura ↔ postgres on envio-network: Postgres connection failed,
      #   "Host": "Unknown or invalid host", container envio-hasura (unhealthy),
      #   dev aborts: "Hasura did not become healthy on port 8888 within 120 s."

    Fix applied (narrow; only envio's own bridge; reverted after the run):

      sudo nft add rule inet filter forward iifname "br-7e7a78547dd3" oifname "br-7e7a78547dd3" accept
      # → rule added, handle 16; hasura restarted → "Up (healthy)",
      #   logs: "Starting API server" ... normal startup.

(c) Port conflict: the host already publishes a service on 127.0.0.1:8080
    (verified `ss -tln`), which is Hasura's default external port. The local
    runs set HASURA_EXTERNAL_PORT=8888 (in indexer/.env and the shell).

(d) pnpm 11 blocked esbuild's build script during `envio init`
    (ERR_PNPM_IGNORED_BUILDS). Fixed with `pnpm approve-builds esbuild`
    (recorded in indexer/pnpm-workspace.yaml → allowBuilds).
