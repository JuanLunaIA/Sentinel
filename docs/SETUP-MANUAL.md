## 2. Perpl testnet exchange account  (REQUIRED before API orders work)

**Why:** API auth alone is not enough — the Exchange needs an on-chain account (`createAccount`)
AND order forwarding enabled (`allowOrderForwarding`). Without the account, authenticated
calls return 404; without forwarding, orders are acked then fail with `sr: 34`.

Easiest path (UI):
1. Open **https://testnet.perpl.xyz** and connect the wallet.
2. Use **"Deposit to Enable trading"** — this creates the exchange account with your first
   deposit. Testnet minimum account open amount is **100 AUSD** (`min_account_open_amount =
   100000000`, 6 decimals; live context).
3. Enable **One-Click Trading** (user settings) — this calls `allowOrderForwarding(true)`.
4. Get testnet collateral (AUSD, token `0xa9012a055bd4e0edff8ce09f960291c09d5322dc`): follow the
   testnet deposit flow on the Perpl UI; if you need a starting balance, use the testnet faucet
   affordance in the same deposit dialog (flow to confirm in UI — mark result below).

Manual / fallback path (Foundry `cast` is installed at `~/.local/bin/cast`):
```bash
export RPC_URL=https://testnet-rpc.monad.xyz
export EXCHANGE=0x1964c32f0be608e7d29302aff5e61268e72080cc
export USD_TOKEN=0xa9012a055bd4e0edff8ce09f960291c09d5322dc   # testnet AUSD (6 dec)
export WALLET=0xYOUR_WALLET
# account exists? (reverts if none)
cast call --from $WALLET $EXCHANGE "getAccountByAddr(address)(uint256)" $WALLET --rpc-url $RPC_URL
# if none: approve + createAccount (100.000000 AUSD)
cast send --from $WALLET $USD_TOKEN "approve(address,uint256)(bool)" $EXCHANGE 100000000 --private-key $WALLET_KEY --rpc-url $RPC_URL
cast send --from $WALLET $EXCHANGE "createAccount(uint256)(uint256)" 100000000 --private-key $WALLET_KEY --rpc-url $RPC_URL
# enable order forwarding
cast send --from $WALLET $EXCHANGE "allowOrderForwarding(bool)" true --private-key $WALLET_KEY --rpc-url $RPC_URL
```
