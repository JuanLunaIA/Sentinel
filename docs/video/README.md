## Reproduce the machine-made clips

```bash
# 0. Prereqs on PATH: node, ffmpeg, asciinema (pipx install asciinema)
#    Dashboard must be live for the dashboard clips:
#      ./target/release/sentinel --mode testnet   # serves :8081

# 1. Record terminal demos -> docs/video/casts/*.cast
bash tools/video/record-terminal-demos.sh

# 2. Render every clip -> docs/video/rendered/*.mp4
bash tools/video/build-videos.sh all
```

## Recording the human-narrated videos

Use OBS Studio (or any screen recorder):

```bash
sudo pacman -S obs-studio pavucontrol    # Artix/Arch
```

OBS setup:
- **Sources**: Display Capture (your monitor) + Audio Input Capture (mic) + Audio Output Capture (desktop)
- **Output**: MP4, 1920x1080, 30 fps
- **Terminal**: font size ≥ 14pt so text is legible in the recording

## Tool inventory (this pipeline)

| Tool | Role | Path |
|---|---|---|
| `capture-frames.cjs` | Drives headless Chrome over CDP, screenshots a URL at a fixed fps into numbered JPEGs | `tools/video/` |
| `cast-to-html.cjs` | Parses an asciinema `.cast` into a terminal-styled HTML page that types it out | `tools/video/` |
| `record-dashboard.cjs` | (Playwright variant; CDP path is preferred) | `tools/video/` |
| `record-terminal-demos.sh` | Records the four terminal demos with asciinema | `tools/video/` |
| `build-videos.sh` | Orchestrates cast→html→frames→mp4 and dashboard→frames→mp4 | `tools/video/` |

All clips are H.264 / yuv420p / `+faststart` — playable everywhere, uploadable
as-is.
