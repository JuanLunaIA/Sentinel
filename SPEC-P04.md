## 3 Normative rules

### 3.1 Liquidation math (exact)

Units: all `Decimal` in real units. `mmr = market.maintenance_margin_fraction`
(e.g. `0.05`). `side = +1` for long (`size > 0`), `-1` for short (`size < 0`).
`notional = |size| * entry_price` for the requirement (SDK semantics: the
maintenance requirement is entry-price-based).

```
MMR    = entry_price * |size| * mmr          # maintenance requirement
liq    = entry + side * (MMR - collateral) / |size|
```

Closed forms (used in tests):
`liq_long  = entry * (1 + mmr) - collateral / |size|`
`liq_short = entry * (1 - mmr) + collateral / |size|`

**SDK unit vectors** (from `vendor/dex-sdk` tests — must pass):
entry 100, size 10, collateral 100, mm 20 ⇒ `mmr = 0.05`:
`liq_long = 95`, `liq_short = 105`, `bankruptcy_long = 90`, `bankruptcy_short = 110`.

`distance_to_liq_pct = |mark - liq| / mark * 100` (percent of mark; mark from
`pos.mark_price`, liq from [`effective_liq_price`]). `None` whenever a needed
input is missing or `mark <= 0`.

### 3.2 Effective price, divergence, margin health

- `effective_liq_price`: exchange `pos.liq_price` when present (source
  `Exchange`), else derived via `implied_liq_price` (source `Derived`), else
  `None`.
- `liq_divergence_pct`: when BOTH prices available,
  `|derived - exchange| / exchange * 100`; else `None`. Rule of use (app
  layer): agreement target ≤ 0.5 % in the property tests; if > 2 % trust the
  exchange price and raise a data-quality warning (the warning is emitted by
  callers — core has no logging).
- `margin_health(pos, market) = (collateral + upnl) / (mmr * notional_mark)`,
  `upnl = (mark - entry) * size` (signed size handles short), `notional_mark =
  |size| * mark`. **1.0 = exactly at the maintenance requirement**; `None` when
  mark missing or notional is zero. Uses `market` for `mmr`.

### 3.3 Tier boundaries (deterministic; `>=` cuts)

`distance_pct >= soft → Green`; `>= warn → Yellow`; `>= hard → Orange`;
otherwise `Red`. A value exactly at a threshold belongs to the **safer** tier.
Monotonicity: a larger distance never yields a more severe tier.

### 3.4 Intent rules table

`ReflexConfig { reduce_fraction (0,1], orange_fraction (0,1], cooldown_ms,
stale_reduce: bool }`, `Default = { 0.5, 0.25, 600_000, false }`.

Stateless `reflex_intent(pos, tier, quality, cfg)`:

| tier | quality | result |
|---|---|---|
| Green / Yellow | any | `None` (Yellow consult is P07's job) |
| Red | Fresh | `Reduce { fraction: cfg.reduce_fraction, reason }` |
| Orange | Fresh | `Reduce { fraction: cfg.orange_fraction, reason }` |
| Orange / Red | `Stale{..}` or `Missing` | `cfg.stale_reduce == true` ⇒ `Reduce { fraction: cfg.orange_fraction, reason: stale }`; else `Alert { message }` |
| any | any | never increase exposure (no such intent exists) |

`ReflexState::advance(pos, tier, quality, cfg, now_ms) -> Option<Intent>`
(single decision step; `now_ms` caller-supplied — the only clock):

1. `tier <= Yellow` ⇒ **reset** the market's bookkeeping (clear
   `last_action_ms` and `red_reduced`) and return `None`.
2. If `now_ms - last_action_ms < cfg.cooldown_ms` (same market) ⇒ `None`
   (cooldown not yet elapsed; equality counts as elapsed).
3. Red + Fresh: if `red_reduced` was already set ⇒ `Close { reason }`; else set
   `red_reduced` and return `Reduce { cfg.reduce_fraction }` (first breach).
4. Orange + Fresh ⇒ `Reduce { cfg.orange_fraction }`.
5. Stale/Missing + (Orange|Red) ⇒ the stateless branch's result (alert or
   gated reduce).
6. Any returned Some(intent) records `last_action_ms = now_ms` for that market.

Edge cases: `size == 0` ⇒ `None` everywhere (no notional to protect); positions
on unknown markets are the caller's problem (state is keyed by `MarketId`).

## 7 Verification semantics (independent)

The verifier re-derives every expectation from this spec + FACTS §1.7 using its
OWN tooling (Python `decimal` for exact arithmetic — cite the command and its
output in the test comments), never reading `risk.rs`. Minimum corpus:

- SDK vectors (95/105/90/110) and their exact `distance_to_liq_pct` values.
- Boundaries: distance exactly `soft`/`warn`/`hard` ⇒ Green/Yellow/Orange.
- Monotonicity sweep + long/short mirrored symmetry (same tier for mirrored
  constructions) + zero/negative-size and huge-collateral-Green cases.
- Divergence: `liq_price` set equal to derived ⇒ divergence ≈ 0 (≤ 0.5 %);
  set 5 % off ⇒ divergence ≈ 5 % and effective price stays `Exchange`.
- State machine sequences: Red@t0 ⇒ Reduce; t0+cooldown−1 ⇒ None; t0+cooldown
  ⇒ Close; recovery reset (Yellow ⇒ None, Red again ⇒ Reduce); Orange cadence;
  stale gate both branches (`stale_reduce` true ⇒ Reduce 0.25, false ⇒ Alert).
