## 1 Purpose

Deliver the action pipeline behind the reflex brain: a pure **policy gate**
(core), pure **reduce-only order sizing** (core), and the **execution layer**
(the `Executor` trait with DryRun / Recording / Perpl implementations plus the
idempotency + post-fill-verification guard). When this lands, a full decision
(intent → policy → sized order → guarded execution → report) runs end-to-end

Ground truth: `docs/FACTS.md` §1 (order shape, `CloseLong/CloseShort`, `rq`
rules, HTTP batch endpoint, error codes) + `SPEC.md` (P03 API contract).

## 3 Policy gate (pure; `SPEC` normative)

`PolicyEngine::evaluate(intent, account, cfg, day, ctx) -> PolicyVerdict`.
The prompt's four-parameter shorthand cannot carry the trigger/tier inputs its
own asymmetry rule needs; the final signature adds `ctx: &PolicyContext
{ source: PolicySource{Reflex|Strategy|Manual}, tier: RiskTier, market_id }`.

**Check precedence (first failure wins; exact reasons are normative):**

1. `cfg.kill_switch == true` ⇒ `Deny("kill switch engaged")`.
2. `ctx.market_id` not in `cfg.market_allowlist` ⇒ `Deny("market {id} not in allowlist")`.
3. Position resolution: `account.positions` entry with `id == ctx.market_id`;
   missing ⇒ `Deny("no position for market {id}")`. `Intent::Alert` skips 3–7
   ⇒ `Allow`.
4. Reduce-only bias (hard invariant): `Reduce{fraction}` with `fraction <= 0
   || fraction > 1` ⇒ `Deny("invalid reduce fraction")`; `Close` on a flat
   position (`size == 0`) ⇒ `Deny("position already flat")`; `AddCollateral{amount}`
   with `amount <= 0` ⇒ `Deny("collateral amount must be positive")`. No intent
   variant may increase |size| or flip side — by construction; tests assert it.
5. Notional (Reduce ⇒ `fraction × |size| × mark`; Close ⇒ `|size| × mark`;
   AddCollateral ⇒ `amount`): mark missing/`<=0` for Reduce/Close ⇒
   `Deny("mark unavailable for notional")`.
6. Notional > `cfg.max_order_size_usd` ⇒ `Deny("notional exceeds MAX_ORDER_SIZE_USD")`.
7. Notional > `cfg.require_approval_above_usd` ⇒ `NeedsApproval("notional above approval threshold")`
   **unless `source == Reflex && tier == Red`** ⇒ `Allow` (deliberate
   asymmetry: a Red-reflex breach executes immediately, still bounded by rule 6).
8. `day.actions_today >= cfg.max_daily_actions` ⇒ `Deny("daily action cap reached")`.
   `actions_today` counts *executed* actions; the caller increments after execution.

## 4 Reduce-only sizing (pure; core `order.rs`)

```
size = quantize_down(|pos.size| × fraction, market.size_decimals)   # lot grid 10^-d
skip (None) when: fraction not in (0,1] · |pos.size| == 0 ·
                  size == 0 after quantization · size < market.min_size
size is clamped <= quantize_down(|pos.size|, d)   # never exceeds the position
```

`OrderRequest { market_id, close: CloseLong (long) | CloseShort (short),
size (real units), order_type: Market (default), max_slippage_bps }`. The request also carries `size_decimals` so executors can emit the
gateway's raw integer size (`raw = size × 10^size_decimals`).
`Close` intents use `fraction = 1`. `quantize_size_down(size, decimals)`
truncates towards zero at the lot grid. Unit tests must cover: exact lot
values, quantization truncation (0.1239 @ 3 ⇒ 0.123), min-size skip,
fraction bounds, side mapping, tiny-position ⇒ None.

## 5 Execution layer (app `execution/`)

- `Executor` trait: `async fn submit(&self, order: &OrderRequest) -> Result<ExecutionReport>`
  (generics only — no `dyn` with async-fn-in-trait).
- `PositionProbe`: `async fn position(&self, market_id) -> Result<Option<Position>>`;
  implemented for `perpl::LivePerpl` via `PerplFeed::snapshot` (find by market).
- `ExecutionReport { order, status: ExecutionStatus{Simulated|Submitted|Filled|Partial|Rejected},
  filled_size, avg_price: Option<Decimal>, tx_hash: Option<String>,
  client_order_id, detail, ts_ms }`. Ids: `sentinel-<market_id>-<seq>` with a
  per-executor monotonic `AtomicU64` seeded at construction (later seeded from
  the wallet `lfr`).
- `DryRunExecutor<P>`: fill price = `mark × (1 ∓ slippage_bps/10_000)` (sell =
  lower); full size; status `Simulated`; appends the report as one JSON line to
  its report path (create parent dirs). Missing mark ⇒ `Err(PerplError::Order)`.
- `RecordingExecutor`: pass-through; persists `{request, report}` JSONL lines
  for tests; status `Simulated`, `avg_price = None`.
- `PerplExecutor<P>`: builds the **gateway HTTP batch** body
  `{"d":[OrderSpec]}` with `OrderSpec { rq, mkt, acc, oid: None, t: 3|4,
  p: 0, s: <raw size = size × 10^size_decimals>, fl: 0, lv: 0, lb: 0,
  ms: max_slippage_bps }` — signed via `ApiKeySigner::signed_request_headers`
  POSTed to `{api}/v1/trading/orders`; maps `mt:31 statuses[0].code`:
  `0 ⇒ Submitted` (ack = forwarded), non-zero ⇒ `Rejected{code}`; 401/403 map
  to `PerplError::Order`. Single attempt (no auto-retry). `tx_hash = None`
  (forwarded by the exchange; gasless). No new deps.
- `IdempotencyStore { window, path }`: in-memory `HashMap<key, last_ms>` JSON
  persisted to `data/idempotency.json` **on every record** for restart safety;
  loads on construction; prunes entries older than the window. Boundary: still suppressed while `now − last < window_ms`; at
exactly the window it is allowed again.
  Key = `"{market_id}:{action}:{size_bucket}"`, `action ∈ {reduce, close,
  collateral}`, `size_bucket = truncate(size × 100)` (hundredths of base units).
- `GuardedExecutor<E, P>`: pre-check `store.check_and_record(key)`; duplicate
  within the window ⇒ `Err(SentinelError::DuplicateOrder { window_secs, key })`
  (new error variant; parent adds it in prep). On success: submit; then within
  `verify_after` poll `probe.position(market)` until `|size|` decreased
  (`Filled`/`Partial` by comparison); timeout ⇒ report kept (`Submitted`) +
  `tracing::warn!` (alert is P11's job) — one reprice/retry is a TODO, not now.
