## 1 Purpose — the Trust-track differentiator

Every decision Sentinel ever makes becomes **independently provable**: a
tamper-evident SHA-256 hash chain in `sentinel-core::audit`, anchored on
Monad through `SentinelAuditAnchor`, verifiable by anyone with the local
journal + `eth_getLogs`. `audit-verify` prints the demo's Trust beat.

**Live status:** contract deploy + live anchors need the funded
`RPC_SIGNER_KEY` on Monad testnet → PENDING-WALLET (STUB-17). Everything else
(chain math, journal, contract, anchor service, CLI, API) is proven offline,
including an **anvil end-to-end** (local chain, real alloy calls).

## 2 Journal format (normative)

Canonical JSON entry, keys sorted, one line per entry
(`journal-YYYYMMDD.jsonl`, UTC day):

```json
{"account":"0x…","decision":{…},"entry_hash":"<64 hex>","execution":{…},
 "input_hash":"<64 hex>","market_id":32,"policy_verdict":{…},
 "prev_hash":"<64 hex>","seq":7,"trigger":"REFLEX","ts":"2026-10-06T02:00:00Z"}
```

- `trigger ∈ REFLEX|STRATEGY|HUMAN|BACKTEST|SYSTEM` (SCREAMING serde).
- `entry_hash = hex(sha256( raw32(prev_hash) ++ canonical_bytes(entry minus
  {prev_hash, entry_hash}) ))`; genesis `prev_hash` = 64 zeros.
- `canonical_json(v)` = `serde_json::to_string(v)` (BTreeMap ⇒ sorted keys,
  compact — no floats in our payloads).
- `input_hash = hex(sha256( concat(canonical_json(part_i)) ))` over the
  parts fed to the decision (helper `hash_input(&[&Value])`).
- Persist = **O_APPEND single-line writes** (create dirs; < 4 KB lines).

## 3 Core API (`sentinel-core::audit`, replaces the P02 stub; `sha256`
helper stays). `std::fs` is allowed here (no network deps, P00 #4 intact).

`Trigger`, `AuditEntry` (fields exactly §§2), `IntentRecord{trigger,
account, market_id, input_hash, decision: Value, policy_verdict: Value}`,
`OutcomeRecord{…same context…, execution: Value}`,
`VerifyReport{entries, first_seq, valid_up_to_seq, last_hash, broken_at,
detail}`, `GENESIS_PREV_HASH`.

- `AuditEntry::new(seq, ts, trigger, account, market_id, input_hash,
  decision, policy_verdict, execution, prev_hash) -> AuditEntry` (computes
  `entry_hash`).
- `AuditEntry::compute_hash(&self)`; `canonical_json`; `hash_input`.
- `append_line(path, entry)`; `verify_chain(path) -> Result<VerifyReport>`
  (recompute every hash; `prev == previous entry_hash`; report
  `broken_at` = exact seq of the first bad entry; tolerate a malformed
  TRAILING line as torn-write with warn, any other malformed line = broken).
- `AuditJournal{dir}`: `open(dir)` resumes `seq`/`last_hash` from the
  lexicographically-latest `journal-*.jsonl` (last VALID line; empty ⇒
  genesis); `seq()`; `record_intent(&IntentRecord, ts) -> Result<AuditEntry>`
  (execution `{"status":"pending"}`); `record_outcome(&OutcomeRecord, ts)
  -> Result<AuditEntry>`; `read_entries(from_seq, limit)`. Day rotation: new
  UTC day ⇒ new file; `prev_hash` continues across files.
- Crash safety: `kill -9` mid-run ⇒ `open()` resumes from the last valid
  line; the chain still verifies (acceptance test).

## 4 Contract (`contracts/`) — Foundry project

`foundry.toml` (src = "src", test = "test", solc 0.8.x stable via foundry
default), `src/SentinelAuditAnchor.sol`, `test/SentinelAuditAnchor.t.sol`.

```solidity
event DecisionAnchored(uint64 seq, bytes32 entryHash, bytes32 runningRoot, address account);
event Heartbeat(address guardian, bytes32 riskStateHash, uint32 openPositions, uint8 maxTier);

error StaleSeq(uint64 got, uint64 want);
mapping(address => uint64) public lastSeq;   // replay guard (only storage)
mapping(address => bytes32) public lastRoot;

function anchor(uint64 seq, bytes32 entryHash, bytes32 runningRoot) external;
  // require seq == lastSeq[msg.sender] + 1 else revert StaleSeq; update; emit
function batchAnchor(uint64 fromSeq, bytes32[] calldata entryHashes, bytes32 root) external;
  // require fromSeq == lastSeq+1; toSeq = fromSeq + len - 1 (len > 0);
  // lastSeq = toSeq; lastRoot = entryHashes[len-1];
  // emit DecisionAnchored(toSeq, entryHashes[len-1], root, msg.sender)
function beat(bytes32 riskStateHash, uint32 openPositions, uint8 maxTier) external; // emit only
```

`forge test`: guard rejects wrong seq (both fns), accepts the exact next
seq / fromSeq, batch math (toSeq, lastRoot), event args via vm.expectEmit,
beat emits. No constructor args. No other storage.

## 5 Rust anchor service (`sentinel::anchor`, app crate)

- `#[allow(async_fn_in_trait)] pub trait AnchorSink { async fn
  anchor_batch(&self, from_seq: u64, entry_hashes: &[String], root: &str)
  -> Result<String /*tx hash*/>; async fn beat(&self, risk_state_hash:
  &str, open_positions: u32, max_tier: u8) -> Result<String>; }`
- `AlloyAnchorSink::new(cfg) -> Result<Self>` (provider = RPC url,
  wallet = `RPC_SIGNER_KEY`, contract = `ANCHOR_CONTRACT_ADDRESS`); `sol!`
  interface mirroring §4. Missing/placeholder config ⇒ `Err` with a clear
  PENDING-WALLET message.
- `pub fn merkle_root(hashes: &[String]) -> String` — pairwise
  sha256(left‖right), odd tail promoted, single ⇒ itself, empty ⇒ 64 zeros.
- `pub fn risk_state_hash(canonical_summary: &str, max_tier: u8) -> String`
  = sha256 over `{"max_tier":u8,"summary":"…"}` canonical.
- `pub async fn run<S: AnchorSink>(cfg, journal: Arc<Mutex<AuditJournal>>,
  sink: S, shutdown: watch::Receiver<bool>) -> Result<AnchorRunReport>`:
  every `HEARTBEAT_INTERVAL_SECS` `beat(...)` (summary = canonical JSON of
  {positions: len, free_balance, equity, max_tier}); every 60 s (or
  immediately when new entries exist and any has trigger REFLEX) batch the
  un-anchored tail: read entries with `seq > last_anchored`, compute
  `merkle_root` of their entry_hashes, `anchor_batch`; RPC failure ⇒
  exponential backoff (1s→30s) and KEEP retrying (journal is the source of
  truth; nothing is lost). `last_anchored` starts at the contract's
  `lastSeq` read at startup when reachable, else 0/`--from` env
  `ANCHOR_FROM_SEQ` override. Track and return counts.

## 6 CLI `src/bin/audit_verify.rs` (`[[bin]] name = "audit-verify"`)

prints exactly:

✅ journal consistent; {N} entries; {M} anchored; root matches at seq {X}

(with `❌ broken at seq {S}: {detail}` on failure; explorer links for the

`--journal <path>` (default latest file under `data/audit/`), `--from-block`,
`--no-chain` (local-only). Exit 0/1.

## 8 Pipeline wiring (parent-owned, in prep)

`Pipeline` gains `journal: Option<Arc<Mutex<AuditJournal>>>` (default None
— P06 tests untouched) + `with_journal(...)` builder. In the run loop, for
every emitted `Decision`: journal the INTENT before any submission
(`input_hash = hash_input([account_json, {"now_ms": …}])`; `decision` JSON =
decision_id/market/tier/action/order; `policy_verdict` JSON = verdict+note;
`account` = `cfg.perpl.account` string). Then: order path ⇒ after the
executor report, journal the outcome (status executed/duplicate/failed,
order_id, tx_hash, fill); no-order paths (deny/needs_approval/none) ⇒
journal the outcome immediately (status `denied`/`needs_approval`/`none`).
Journal failures: `tracing::error!` + PROCEED (a rescue action outranks
audit availability; P16 revisits buffering). Parent integration test:
crash-fixture run ⇒ journal pairs (2× per action), exact `seq` continuity,
`verify_chain` green, and a truncated-tail resume test.
