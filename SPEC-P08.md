## 2 Design mapping (read carefully)

"ProviderChain" semantics live **inside `StrategyEngine`**: the engine holds
`provider: P` plus an **optional** `fallback: F` and one [`CircuitBreaker`]
per slot. `chain.rs` exports the breaker primitives and `NoProvider`.

```rust
// chain.rs
pub enum BreakerState { Closed, Open { until_ms: u64 }, HalfOpen }
pub struct CircuitBreaker { /* threshold, open_ms, failures, open_until_ms */ }
impl CircuitBreaker {
    pub fn new(threshold: u32, open_ms: u64) -> Self
    pub fn state(&self, now_ms: u64) -> BreakerState
    pub fn is_available(&self, now_ms: u64) -> bool
    pub fn record_success(&mut self)
    pub fn record_failure(&mut self, now_ms: u64)
}
pub struct NoProvider;              // Provider: complete ⇒ AllProvidersFailed; name "none"
```

Breaker semantics (frozen): `record_failure` increments `failures`; when
`failures >= threshold` **or the call was a half-open probe**, set
`open_until_ms = now + open_ms` (half-open failure re-opens for a full
window). `state(now)`: `Open{until}` while `now < until`; at
`now >= until` ⇒ `HalfOpen` (single probe allowed); `record_success` ⇒
`Closed` (failures = 0). `is_available(now)` = `Closed | HalfOpen` (i.e.
anything except unelapsed `Open`).

## 3 Engine changes (`brain/engine.rs`)

Type: `pub struct StrategyEngine<P: Provider, F: Provider = NoProvider>`
holding `provider: P`, `fallback: Option<F>`, `breakers: Mutex<[CircuitBreaker; 2]>`,
`forced_fail: Option<String>`, plus the P07 fields and the budget fields.

- `new(provider, min_interval_secs, confidence_floor)` — unchanged signature,
  `fallback: None`, breakers `(3, 300_000)`.
- `with_fallback(self, fallback: F) -> StrategyEngine<P, F>` — sets `Some`.
- `with_forced_failure(self, name: impl Into<String>) -> Self` — provider name
  to force-fail (checked by name equality; no network call).
- `with_budget(self, max_consults_per_hour: u32, max_tokens_per_day: u64) -> Self`.
- `ConsultOutcome` gains `failover_from: Option<String>` (additive).

`consult(&self, input, now_ms)` — extended flow (all P07 semantics preserved
when `fallback == None`):

1. Rate limit — unchanged.
2. **Budget guard** (before any provider call): sliding hour window
   (`now − ts < 3_600_000`, `VecDeque<u64>`) ≥ `max_consults_per_hour`, or
   sliding day window (`< 86_400_000`, `VecDeque<(ts, est_tokens)>`) summed ≥
   `max_tokens_per_day` ⇒ return a **synthetic outcome**: decision
   `{action: ESCALATE, market_id: focus, amount: None, confidence: 0,
   urgency: CRITICAL, reason: "strategy budget exceeded — human review
   required"}`, `provider_used: "budget"`, `failover_from: None`,
   `repaired: false`, `downgraded: false` + `tracing::warn!`. The attempt is
   still counted (hour) and the rate slot recorded.
3. **Attempt(primary)**: forced-fail by name ⇒ failure class `forced`
   (no call); breaker unavailable ⇒ class `circuit_open` (no call); else
   `complete()` (Err ⇒ `http`/`transport`), then parse → on parse error one
   repair call → on error again class `invalid_output`. Success ⇒
   `record_success`, outcome `{provider_used: P::name(), failover_from: None}`
   with P07 fields.
4. **Attempt(fallback)** only when `fallback == Some(F)` and primary failed:
   same flow. Success ⇒ `{provider_used: F::name(), failover_from:
   Some(P::name())}`. Failure ⇒ the primary's error is replaced by
   `AllProvidersFailed { last: "{primary_name}: {primary_class}; {fallback_name}: {fallback_class}" }`.
5. **No fallback configured**: return the primary's own error exactly (P07
   corpus compatibility — `InvalidJson`/`InvalidDecision`/etc. unchanged).
6. Every failover emits `tracing::warn!(provider = primary, failover_to =
   fallback, error_class, "provider failed; failing over")`.
7. Budget accounting: every consult that reaches step 3 adds
   `est_tokens = prompt_tokens.unwrap_or((system.len()+user.len())/4) +
   completion_tokens.unwrap_or(text.len()/4)` of the winning call (0 for
   synthetic/budget outcomes).

  Closed; 3rd ⇒ Open{until=now+open_ms}; `is_available` false inside,
  true at exactly `until` (HalfOpen); half-open success ⇒ Closed+reset;
  half-open failure ⇒ Open again with a fresh full window; `record_success`
  resets a partially-failed breaker.
- `engine2`: failover-on-http (primary Err ⇒ fallback Ok, `provider_used`
  = fallback name, `failover_from` = primary name); failover-on-invalid-output
  (primary returns unparseable twice ⇒ fallback); failover-on-validation
  (primary yields schema-invalid ⇒ fallback); **no fallback ⇒ P07 error
  semantics byte-identical** (repair-still-bad ⇒ `InvalidJson{provider}`,
  validation ⇒ `InvalidDecision`); forced-fail skips primary without a call
  (calls() proves it) and does NOT consult the primary's breaker? (freeze:
  forced failure DOES record a breaker failure — simplest honest account);
  all-failed ⇒ `AllProvidersFailed{last}` containing BOTH names + classes;
  breaker opens after 3 consecutive failures and the 4th consult SKIPS the
  primary (fallback called immediately, primary calls() count frozen);
  breaker half-open recovery through the engine (advance now_ms by
  open_ms+1, next consult probes primary again); budget: N=2/hour — 2

- Verifier (`tests/chain_adversarial.rs`, black box): breaker boundary
